# Gears and Greens
Gears and Greens is a lightweight Forge 1.20.1 survival modpack built around **Create** mechanical engineering and farming gameplay powered by Farmer's Delight.

This pack mixes mechanical automation and cozy farm life. You can build complex gear contraptions, conveyor belts and automated production lines from Create, while growing crops, raising farmland and cooking homemade meals with Farmer's Delight. It keeps the vanilla survival feeling, but adds lots of fun engineering and cooking content without overwhelming new players.

## Included Mods
- Create: Build gears, belts, mechanical arms and automated systems
- Farmer's Delight: New crops, kitchen tools, cooking pots and homemade food
- Xaero's Minimap & World Map: Convenient map and waypoint system for exploration
- Geckolib: Animation library for many mods
- Cloth Config: Unified configuration menu support
- WTHIT: View block and item information by hovering
- CustomSkinLoader: Load custom player skins
- Other quality-of-life mods to improve your game experience.

## Pack Information
- Compatible for both single-player and multiplayer server.
- All mods will automatically download from CurseForge when you import this pack with supported launchers.
- This modpack contains custom config files, RhythmCraft chart and song files inside overrides. These custom files are only configuration and game resources, no modified mod jars are included.
- More mods may be added in future updates to expand gameplay and bring extra features.
